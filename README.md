## ✦ عن المشروع

لوحة الإدارة الخاصة بمنظومة **NOVATEK**. تم اعتماد واجهة عربية من اليمين إلى اليسار، مع هوية مرئية سوداء وبيضاء وبرتقالية، والتركيز على سهولة الاستخدام من الهاتف والكمبيوتر.

## 🧭 الأقسام

| القسم | الوظيفة |
|---|---|
| الرئيسية | ملخص العمليات، المبيعات، الطلبات، المخزون وآخر الحركة |
| الطلبات | متابعة الطلبات وحالاتها |
| المنتجات | إدارة كتالوج اللابتوبات والمخزون والأسعار |
| المستخدمون والعملاء | إدارة حسابات العملاء ومراجعة بياناتهم |
| المحفظة | مراجعة طلبات تعبئة الرصيد |
| طلبات المواقع | متابعة طلبات تصميم وتطوير المواقع |
| الخدمات والعمليات | متابعة الطلبات الرقمية والعمليات التشغيلية |
| تحليلات المبيعات | عرض مؤشرات الأداء المتاحة |
| تحليلات الذكاء الاصطناعي | سجل الاستخدام والتوكنات والتكلفة المسجلة وزمن الاستجابة والأخطاء |
| API والتكاملات | إدارة إعدادات التكاملات المتاحة |
| الكوبونات والمكافآت | إدارة العروض والمكافآت |
| الإشعارات والتنبيهات | متابعة التنبيهات والنشاطات |
| المشرفون والإعدادات | إدارة صلاحيات الإدارة والإعدادات المركزية |

> تعتمد البيانات الظاهرة على اتصال Supabase والجداول المتاحة. لا تُعرض أرقام افتراضية عند غياب البيانات. إنشاء جدول تحليلات الذكاء الاصطناعي وحده لا يسجّل الأحداث تلقائياً؛ يجب أن تسجّل الخدمات أحداث الاستخدام فعلياً.

## 🎨 الهوية والتصميم

- ألوان NOVATEK: أسود، أبيض، وبرتقالي `#F0821E`.
- تخطيط عربي RTL وخط IBM Plex Sans Arabic.
- قوائم جانبية للكمبيوتر وقائمة قابلة للفتح على الهاتف.
- تحسينات لتقليل تجاوز المحتوى والجداول لحدود شاشة الهاتف.

## 🧰 المتطلبات

- Node.js متوافق مع إصدار Next.js المستخدم.
- مشروع Supabase وإعدادات المصادقة المناسبة.
- متغيرات البيئة المطلوبة موضحة في `.env.example`.

## 🚀 التشغيل محلياً

```bash
npm ci
cp .env.example .env.local
# املأ القيم المطلوبة محلياً ولا ترفع .env.local إلى GitHub
npm run dev
```

لفحص نسخة الإنتاج:

```bash
npm run build
```

## 🔐 الأمان

- لا تضع مفاتيح API أو أسرار Supabase في README أو ملفات الواجهة العامة.
- استخدم متغيرات البيئة السرية في بيئة النشر.
- راجع صلاحيات المدير وسياسات RLS قبل النشر الإنتاجي.
- لا تعتبر نجاح `git push` دليلاً على نجاح البناء أو اختبار جميع عمليات قاعدة البيانات.

## 📦 الإصدارات

- `V72.0.1` — تحسين أولي لتخطيط الهاتف.
- `V72.0.2` — توحيد الهوية البصرية، تحسين لوحة المعلومات، إضافة اختصارات تشغيلية، وتحسين استجابة التخطيط على الشاشات الضيقة.
- `V72.0.3` — تحديث تلقائي للوحة الرئيسية كل دقيقة مع وقت آخر تحديث، مركز اختصارات تشغيلية موسّع، وصول أسرع لأقسام المحفظة وطلبات المواقع والعملاء، واختصار لوحة المفاتيح `Ctrl/⌘ + K` للبحث الشامل و`Esc` لإغلاق النتائج والقائمة. كما أضيفت تحسينات للتركيز بلوحة المفاتيح وتقليل الحركة وتحسين عرض مركز المتابعة على الهاتف.
